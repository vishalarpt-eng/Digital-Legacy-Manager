# Digital Legacy Manager

## Project Overview

Digital Legacy Manager is a software project that
demonstrates secure organization and controlled
transfer of digital assets to authorized beneficiaries.

## Features

- Create and view digital assets
- Assign beneficiaries
- Create a digital will
- Define transfer conditions
- REST API using FastAPI
- Automated tests using pytest

## Technologies

- Python
- FastAPI
- Git and GitHub
- Pytest

## Installation

Clone the repository:

    git clone YOUR_REPOSITORY_URL

Navigate to the project:

    cd Digital-Legacy-Manager

Install dependencies:

    pip install -r requirements.txt

Run the application:

    uvicorn src.app:app --reload

## API Documentation

Open http://127.0.0.1:8000/docs

## Run Tests

    python -m pytest -v
